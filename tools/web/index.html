    未检测到 XS16 键盘 · 排查帮助

    若「连接键盘」弹窗里没有 XS16 设备，或列表中始终为空，通常是因为系统（尤其 Linux 内核）在为键盘创建 /dev/hidraw* 节点时偶发失败，导致浏览器根本看不到它。

    1. 确认 XS16 键盘已通过 USB 正常连接；
    2. 重新拔插键盘（拔下再插上），等待 1~2 秒；
    3. 点上方「刷新」按钮重新枚举；
    4. 若仍为空，点「连接键盘」在系统弹窗中勾选该设备；
    5. Linux 下若提示无权限（或设备节点不可访问），请按以下步骤添加 udev 规则（只需做一次）： 
      # 1. 新建规则文件（写入 XS16 的 VID/PID 并放开权限）
echo 'SUBSYSTEM=="hidraw", ATTRS{idVendor}=="4c58", ATTRS{idProduct}=="5310", MODE="0666"' \
  | sudo tee /etc/udev/rules.d/99-xs16-keyboard.rules

# 2. 重新加载规则并触发，使其立即生效
sudo udevadm control --reload-rules
sudo udevadm trigger

# 3. 重新拔插两个键盘，刷新本页后再点「连接键盘」
      临时替代方案（重启会失效）：sudo chmod 666 /dev/hidraw* 后刷新页面。
